Part 1: Background

1 What is Minimax Algorithm?

Definition: Minimax is a recursive algorithm used for decision-making in two-player zero-sum games. It assumes both players play optimally – MAX tries to maximize the score, MIN tries to minimize it.

Key Terminology:

  • MAX Player: The player we are helping (tries to maximize the score)
  • MIN Player: The opponent (tries to minimize the score)
  • Terminal states: End of the game (win, loss, or draw)
  • Utility values: Numbers assigned to terminal states (e.g., +1 for win, -1 for loss, 0 for draw)
🌲 Example Game Tree: 
                    MAX
                   /   \
                  /     \
                 /       \
               MIN       MIN
              /   \     /   \
            MAX   MAX  MAX   MAX
           /  \  /  \ /  \  /  \
          5   3 8   2 7   4 9   1

Part 2: Algorithm and Pseudocode

2 Minimax Algorithm

Algorithm Steps:

  1. Generate the complete game tree from the current state.
  2. Assign utility values to the leaf nodes (terminal states).
  3. Propagate values upward using the minimax rule:
    • At MAX nodes: value = maximum of children's values
    • At MIN nodes: value = minimum of children's values
  4. The value at the root is the best outcome MAX can guarantee.
  5. The move that leads to that child is the optimal move.

Pseudocode:

function MINIMAX(node, depth, isMaximizingPlayer):
    if node is terminal:
        return utility(node)

    if isMaximizingPlayer:
        best = -∞
        for each child of node:
            value = MINIMAX(child, depth+1, False)
            best = max(best, value)
        return best
    else:
        best = +∞
        for each child of node:
            value = MINIMAX(child, depth+1, True)
            best = min(best, value)
        return best

Part 3: Alpha-Beta Pruning

3 What is Alpha-Beta Pruning?

Definition: Alpha-Beta pruning is an optimization technique for minimax that cuts off branches that cannot affect the final decision. It makes the search faster without changing the result.

Parameters:

  • α (Alpha): Best value that MAX can guarantee so far (starts at -∞)
  • β (Beta): Best value that MIN can guarantee so far (starts at +∞)

Pruning Rules:

  • At a MAX node: If α ≥ β, prune remaining branches
  • At a MIN node: If β ≤ α, prune remaining branches

Pseudocode:

function ALPHA_BETA(node, depth, α, β, isMaximizingPlayer):
    if node is terminal:
        return utility(node)

    if isMaximizingPlayer:
        best = -∞
        for each child of node:
            value = ALPHA_BETA(child, depth+1, α, β, False)
            best = max(best, value)
            α = max(α, best)
            if β <= α:
                break  // Prune
        return best
    else:
        best = +∞
        for each child of node:
            value = ALPHA_BETA(child, depth+1, α, β, True)
            best = min(best, value)
            β = min(β, best)
            if β <= α:
                break  // Prune
        return best

Benefits of Alpha-Beta Pruning:

  • Evaluates fewer nodes (up to 50% less with optimal ordering)
  • Same result as minimax (no accuracy loss)
  • Allows deeper search within the same time constraints

# Step 2: Minimax without pruning
def minimax(node, is_maximizing):
    # If leaf node, return the value directly
    if isinstance(node, int):
        return node
    
    if is_maximizing:
        best = -999999
        for child in game_tree[node]:
            value = minimax(child, False)
            best = max(best, value)
        return best
    else:
        best = 999999
        for child in game_tree[node]:
            value = minimax(child, True)
            best = min(best, value)
        return best

# Step 3: Minimax with Alpha-Beta Pruning
def alpha_beta(node, is_maximizing, alpha, beta):
    # If leaf node, return the value directly
    if isinstance(node, int):
        return node
    
    if is_maximizing:
        best = -999999
        for child in game_tree[node]:
            value = alpha_beta(child, False, alpha, beta)
            best = max(best, value)
            alpha = max(alpha, best)
            if beta <= alpha:
                break  # Prune
        return best
    else:
        best = 999999
        for child in game_tree[node]:
            value = alpha_beta(child, True, alpha, beta)
            best = min(best, value)
            beta = min(beta, best)
            if beta <= alpha:
                break  # Prune
        return best
