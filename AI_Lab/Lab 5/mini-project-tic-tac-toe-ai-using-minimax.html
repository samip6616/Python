Part 1: Background

1 Tic-Tac-Toe Game

Game Rules:

  • Two players: X (MAX) and O (MIN)
  • X plays first
  • Players take turns placing their mark on a 3×3 board
  • First to get 3 in a row (horizontally, vertically, or diagonally) wins
  • If all 9 squares are filled and no winner, it's a draw

Utility Values:

  • +1 → X wins (MAX player)
  • -1 → O wins (MIN player)
  • 0 → Draw

Minimax in Tic-Tac-Toe:

  • AI (X) is the MAX player – tries to maximize the score
  • Human (O) is the MIN player – tries to minimize the score
  • AI explores all possible moves and chooses the one with the highest minimax value
  • With optimal play, Tic-Tac-Toe always ends in a draw

def print_board(board):
    print()
    for i in range(0, 9, 3):
        print(f" {board[i]} | {board[i+1]} | {board[i+2]} ")
        if i < 6:
            print("---+---+---")

# Step 3: Check if the game is over
def is_winner(board, player):
    # Winning combinations
    win_combinations = [
        [0, 1, 2], [3, 4, 5], [6, 7, 8],  # Rows
        [0, 3, 6], [1, 4, 7], [2, 5, 8],  # Columns
        [0, 4, 8], [2, 4, 6]              # Diagonals
    ]
    for combo in win_combinations:
        if all(board[i] == player for i in combo):
            return True
    return False

def is_draw(board):
    return ' ' not in board

def game_over(board):
    return is_winner(board, 'X') or is_winner(board, 'O') or is_draw(board)

# Step 4: Minimax Algorithm for Tic-Tac-Toe
def minimax(board, is_maximizing):
    # Base cases
    if is_winner(board, 'X'):
        return 1
    elif is_winner(board, 'O'):
        return -1
    elif is_draw(board):
        return 0
    
    if is_maximizing:
        best = -999999
        for i in range(9):
            if board[i] == ' ':
                board[i] = 'X'
                value = minimax(board, False)
                board[i] = ' '
                best = max(best, value)
        return best
    else:
        best = 999999
        for i in range(9):
            if board[i] == ' ':
                board[i] = 'O'
                value = minimax(board, True)
                board[i] = ' '
                best = min(best, value)
        return best

# Step 5: AI makes a move
def ai_move(board):
    best_value = -999999
    best_move = -1
    
    for i in range(9):
        if board[i] == ' ':
            board[i] = 'X'
            move_value = minimax(board, False)
            board[i] = ' '
            
            if move_value > best_value:
                best_value = move_value
                best_move = i
    
    board[best_move] = 'X'
    return best_move

# Step 6: Human makes a move
def human_move(board):
    while True:
        try:
            move = int(input("Enter your move (1-9): ")) - 1
            if move < 0 or move > 8:
                print("Invalid! Enter 1-9.")
            elif board[move] != ' ':
                print("That cell is already taken!")
            else:
                board[move] = 'O'
                return move
        except ValueError:
            print("Invalid! Enter a number.")

# Step 7: Main game loop
def play_game():
    print("=" * 50)
    print("TIC-TAC-TOE (X = AI, O = Human)")
    print("=" * 50)
    print()
    print("You are O. AI is X.")
    print("Enter a number (1-9) to place your move:")
    print()
    print(" 1 | 2 | 3 ")
    print("---+---+---")
    print(" 4 | 5 | 6 ")
    print("---+---+---")
    print(" 7 | 8 | 9 ")
    print()
    
    while not game_over(board):
        print_board(board)
        
        # AI's turn (X)
        print("AI is thinking...")
        ai_move(board)
        
        if game_over(board):
            break
        
        # Human's turn (O)
        print_board(board)
        human_move(board)
    
    # Game result
    print_board(board)
    if is_winner(board, 'X'):
        print("🏆 AI wins! Better luck next time.")
    elif is_winner(board, 'O'):
        print("🎉 You win! Congratulations!")
    else:
        print("🤝 It's a draw! Good game!")

# Step 8: Run the game
play_game()

Part 4: How Minimax Works in Tic-Tac-Toe

4 Algorithm Explanation

1. Base Cases:

  • If X wins → return +1
  • If O wins → return -1
  • If draw → return 0

2. MAX Player (X):

  • For each empty cell, try placing X
  • Call minimax on the new board (MIN's turn)
  • Keep the maximum value
  • Return the best value

3. MIN Player (O):

  • For each empty cell, try placing O
  • Call minimax on the new board (MAX's turn)
  • Keep the minimum value
  • Return the best value

4. AI Move:

  • Try each empty cell as X
  • Get the minimax value for each move
  • Choose the move with the highest value

Game Tree Size:

  • First move: 9 possible moves
  • Second move: 8 possible moves
  • Total: 9! = 362,880 possible games (but many are pruned)
  • With Alpha-Beta, it's much faster

A1 Question 1 Sample Answer

Tic-Tac-Toe is a good game to implement Minimax because:

  • It has a small state space (9! = 362,880 possible games)
  • It's easy to evaluate terminal states (win, lose, draw)
  • It's a zero-sum game (one player's gain is the other's loss)
  • Both players have perfect information

A2 Question 2 Sample Answer

The utility values are:

  • +1 for X (AI) win
  • -1 for O (Human) win
  • 0 for Draw

These are chosen because they are symmetrical and make the minimax calculation simple. +1 and -1 represent opposite outcomes, and 0 represents a neutral outcome.

A3 Question 3 Sample Answer

There are 9! = 362,880 possible games of Tic-Tac-Toe (including invalid games that continue after a win). Minimax handles this by exploring the game tree recursively, evaluating all possible moves, and choosing the optimal one. Alpha-Beta pruning can be used to reduce the number of nodes evaluated.

A4 Question 4 Sample Answer

With optimal play from both sides, Tic-Tac-Toe always ends in a draw. The AI should never lose. If the human makes a mistake, the AI will win. In my games, the AI never lost.

A5 Question 5 Sample Answer

If we changed the utility values (e.g., +10 for win, -10 for loss), the minimax algorithm would still work correctly because it only cares about the relative ordering of values. The AI would still choose winning moves over drawing moves. However, the numbers would be larger, but the behavior would remain the same.

A6 Question 6 Sample Answer

To add Alpha-Beta pruning:

def minimax_alpha_beta(board, is_maximizing, alpha, beta):
    # Base cases same as before
    if is_winner(board, 'X'): return 1
    if is_winner(board, 'O'): return -1
    if is_draw(board): return 0

    if is_maximizing:
        best = -999999
        for i in range(9):
            if board[i] == ' ':
                board[i] = 'X'
                value = minimax_alpha_beta(board, False, alpha, beta)
                board[i] = ' '
                best = max(best, value)
                alpha = max(alpha, best)
                if beta <= alpha:
                    break  # Prune
        return best
    else:
        best = 999999
        for i in range(9):
            if board[i] == ' ':
                board[i] = 'O'
                value = minimax_alpha_beta(board, True, alpha, beta)
                board[i] = ' '
                best = min(best, value)
                beta = min(beta, best)
                if beta <= alpha:
                    break  # Prune
        return best

Time Complexity: O(9!) = O(362,880) in the worst case. With Alpha-Beta pruning, it is much faster.

Space Complexity: O(9) = O(1) for the recursion depth (maximum 9 moves).
